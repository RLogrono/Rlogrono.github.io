# Mi Portafolio Personal

Bienvenido a mi página web personal, un portafolio moderno y dinámico construido con HTML5, CSS3 y JavaScript vanilla.

## 🚀 Características

### 1. **Sección Hero Dinámica**
- Imagen de perfil con efectos de float y escala
- Gradiente animado de fondo con burbujas flotantes
- Indicador de scroll con animación bounce

### 2. **Sección Sobre Mí**
- Textos que aparecen desde la izquierda al hacer scroll
- Grid de habilidades con animaciones escalonadas
- Efectos hover interactivos y elevación

### 3. **Sección de Cita Inspiradora**
- Fondo oscuro con efecto glassmorphism
- Comilla decorativa de fondo
- Animación fade-in-scale al aparecer

### 4. **Sección de Proyectos**
- 3 tarjetas de proyectos con efectos 3D perspective
- Parallax effect en movimiento del mouse
- Animaciones escalonadas al cargar
- Tags con tecnologías utilizadas

### 5. **Sección de Contacto**
- Botones llamados a la acción con hover dinámico
- Links para email, GitHub y LinkedIn
- Gradiente de fondo atractivo

## 🎨 Efectos Dinámicos Implementados

✨ **Intersection Observer** para animaciones de scroll
🔄 **Transform 3D** en tarjetas con mouse parallax
⭐ **Animaciones CSS** fluidas y modernas
📍 **Navbar sticky** con backdrop blur
🎯 **Smooth scroll** automático entre secciones
📱 **Responsive design** perfectamente optimizado

## 📁 Estructura de Archivos

```
├── index.html          # Estructura HTML
├── css/
│   └── styles.css     # Estilos y animaciones
├── js/
│   └── script.js      # Efectos dinámicos e interactividad
└── bornco.jpg         # Foto de perfil
```

## 🛠️ Personalización

Para adaptar la página a tus necesidades:

1. **Foto**: Reemplaza `bornco.jpg` con tu propia imagen
2. **Contenido**: Actualiza datos personales en `index.html`
3. **Colores**: Modifica variables CSS en `styles.css`
4. **Proyectos**: Añade tus proyectos en la sección correspondiente
5. **Contacto**: Actualiza links de email, GitHub y LinkedIn
